# Inventory System Rules

## Tech Stack
- Backend: FastAPI
- ORM: SQLAlchemy
- Database: SQLite (development)
- Frontend: React + Vite + Tailwind CSS

## Rules

- Never redesign existing UI.
- Preserve all Tailwind classes.
- Preserve component structure.
- Never replace working pages.
- Never remove charts or cards.
- Only replace mock data with API data.
- Keep API logic inside service files.
- Use SQLAlchemy ORM only.
- No raw SQL unless requested.
- Follow existing project architecture.
- Never modify authentication unless asked.
- Ask before deleting files.
